# Community code of conduct

Treat contributors respectfully regardless of experience, nationality, identity,
or background. Critique ideas and code without personal attacks. Harassment,
threats, doxxing, discrimination, and publishing others' private information are
not acceptable. Maintain a constructive, welcoming working environment.

Report incidents privately to the repository owner via their published GitHub
contact method. Maintainers may remove content, restrict participation, or ban
contributors to protect the community. Apply this policy fairly and disclose no
reporter's private information. This applies to repository discussions, issues,
reviews, and project representation elsewhere.
