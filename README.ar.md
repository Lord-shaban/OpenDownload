# OpenDownload.

**الملف نفسه. على جهازك. في مساحة عمل مفتوحة المصدر.**

[افتح التطبيق](https://opendownload.lord.blitz.cloud/) / [الموقع](https://opendownload-website.vercel.app/ar) / [English](README.md)

![واجهة OpenDownload الحقيقية تعرض فيديو عامًا من Threads](docs/assets/workspace-video-v2.jpg)

أضف رابطًا عامًا، شاهد الصيغ المتاحة فعلًا، ثم احفظ الفيديو أو الصوت أو الصورة.
التطبيق يدعم العربية وRTL، والمظهرين الفاتح والداكن، وتتبع التقدم والإلغاء وإعادة
المحاولة. الكود مفتوح المصدر بترخيص MIT ولا يحتاج الاستخدام العام إلى حساب.

## المصادر الحالية

| المصدر                                        | الإمكانات                                                          |
| --------------------------------------------- | ------------------------------------------------------------------ |
| LinkedIn                                      | فيديوهات المنشورات العامة وروابط النشاط واختصارات `lnkd.in`        |
| Pinterest                                     | دبابيس الفيديو والصور المفردة الأصلية واختصارات `pin.it`           |
| Threads                                       | فيديو أو صورة مفردة، أو مجموعة صور فقط حتى 20 صورة في ملف ZIP      |
| TikTok وInstagram وX وFacebook وReddit وVimeo | وسائط عامة عبر المستخرجات المتاحة؛ التوفر يختلف حسب الرابط والمضيف |
| SoundCloud والروابط المباشرة                  | صوت عام وملفات فيديو وصوت وصور مباشرة                              |

الإضافات الجديدة موجودة في `main` والتطبيق العام، وليست ضمن حاويات الإصدار
الثابت `v0.1.0`. راجع [حدود المصادر](docs/SOCIAL_SOURCES.md) و[سجل التحقق](docs/VERIFICATION.md).

> للمحتوى العام الذي تملكه أو لديك إذن بحفظه فقط. YouTube والمحتوى الخاص أو
> المدفوع أو الذي يتطلب تسجيل الدخول أو المحمي بـDRM غير متاح. لا تُقبل ملفات
> جلسات الدخول، ولا تُزال العلامات المائية. لا نضمن عمل كل رابط عام.

النسخة العامة تحذف الملفات بعد **15 دقيقة**. احفظ الملف على جهازك قبل انتهاء
الصلاحية. قد يحتاج المضيف المجاني إلى وقت للاستيقاظ.

## شغّل نسختك

```sh
git clone https://github.com/Lord-shaban/OpenDownload.git
cd OpenDownload
cp .env.example .env
docker compose up --build -d --wait
```

افتح **http://localhost:3000**. التطبيق يُتاح محليًا فقط افتراضيًا. لا تغيّر حدود
الشبكة أو تعرّض الخدمة للعامة قبل قراءة [دليل الاستضافة](docs/SELF_HOSTING.md).
يوجد أيضًا [ملف تشغيل سحابي](docs/FENCED_CLOUD.md) للمضيفين المتوافقين مع عزل الشبكة المطلوب.
